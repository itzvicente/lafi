# 🏥 Portal Web de Restock — Droguería LAFI

Un proyecto escolar sencillo para facilitar el reabastecimiento de productos entre las farmacias y la Droguería LAFI.

---

## 📌 ¿De qué trata?
Este sitio web permite a las farmacias realizar pedidos de restock de forma rápida y a la Droguería LAFI administrar su catálogo de productos y controlar los pedidos recibidos.

---

## ✨ Funciones principales
* **Farmacias:** Ver productos disponibles y enviar pedidos de restock.
* **Droguería LAFI:** Agregar/editar productos, ver stock y gestionar los pedidos.
